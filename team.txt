#Development
You are going to be working on your branch and when you finish your work you will submit a pull request to the main branch
with all your changes. After that we are going to merge all the changes to the main branch so that render can update the published site.

In other words:
    - In Trello we are going to track the work we are doing
    - In Github, you are going to create and use a new branch using your name or initials and you will work during the week in that branch. When your
      work is finished you will create a pull request to the main branch so that after review, the code can be marged (added) to the main branch.
      After your pull request has been accepted or closed, you are free to delete that branch that you created for that week.
    - Render is going to be use to publish the site from the main branch
