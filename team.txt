We are going to be working in the branch pre-release. When the activity for X week has been completed,
we are going to merge all the changes to the main branch so that render can update the published site.

    - In Github, we are going to use the branch pre-release to work during the week and the merge the changes to the main branch
    - Render is going to be use to publish the site from the main branch
